# Суть — сайт экономических новостей с понятными шагами

Сайт берёт свежие официальные новости (пока — ленты Банка России), ИИ готовит **черновики** карточек
(«что случилось / кого касается / что делать»), а **вы проверяете и публикуете**. Без вашей отметки
«проверено» карточка на сайт не попадёт — это заложено в код.

Хостинг бесплатный (GitHub Pages), программирование не нужно. Платно только ИИ-черновики: обычно это
копейки за карточку (актуальные цены — на сайте Anthropic).

---

## Что где лежит

| Папка / файл | Что это |
|---|---|
| `content/news/` | карточки новостей (по файлу на карточку). Черновики и опубликованные |
| `content/raw/` | сырые новости из лент (служебное, трогать не нужно) |
| `content/topics.json` | раздел «Темы» |
| `content/courses.json` | курсы и видео сторонних авторов (только с их согласия) |
| `content/examples/` | демо-карточки; на настоящий сайт **не попадают**, видны только в `npm run preview` |
| `config/site.json` | название сайта, ссылка на Telegram, почта, текст-предупреждение |
| `config/sources.json` | откуда собираем новости |
| `.github/workflows/` | автоматика: сбор черновиков и публикация |

---

## Как всё устроено

- Сайт собирается на GitHub Actions (задача «Опубликовать сайт») при каждом изменении в репозитории и выкладывается на GitHub Pages.
- Раз в 3 часа задача «Собрать новости и черновики» читает ленты из `config/sources.json` и, если добавлен секрет `ANTHROPIC_API_KEY`, просит Claude подготовить черновики в `content/news/` (`"status": "draft"`).
- На сайт попадают только карточки со `"status": "published"`, источником и отметкой проверки (`review.by`, `review.at`). Сборка с флагом `--strict` падает, если опубликованная карточка не проходит проверку.

## Ключ для ИИ-черновиков

1. Зарегистрируйтесь на <https://console.anthropic.com>, пополните баланс на небольшую сумму, создайте **API key** (раздел API Keys). Ключ показывают один раз — скопируйте.
2. В репозитории GitHub: **Settings → Secrets and variables → Actions → New repository secret**.
   Имя: `ANTHROPIC_API_KEY`, значение — ваш ключ. **Никому не отправляйте ключ и не вставляйте его в файлы проекта.**
3. Название модели по умолчанию — `claude-sonnet-5`. Если нужна другая, создайте в той же вкладке
   **Variables → New repository variable**: имя `ANTHROPIC_MODEL`, значение — точное название модели из документации
   <https://docs.claude.com/en/docs/about-claude/models>.
4. Установите в Anthropic Console лимит расходов, чтобы не было сюрпризов.
5. **Actions → «Собрать новости и черновики» → Run workflow.** Через минуту-две в папке `content/news/` появятся файлы-черновики.

Ленты Банка России при проверке 21.09.2026 открывались с серверов GitHub. Если когда-нибудь задача напишет «Ни одна лента не открылась» — сайт ЦБ стал блокировать серверы GitHub; тогда сбор нужно запускать на своём компьютере или небольшом сервере (`npm run pipeline`).

## Как опубликовать новость (ежедневная работа)

1. В репозитории откройте `content/news/` и выберите файл-черновик.
2. Нажмите значок карандаша (**Edit**) и **проверьте карточку**:
   - откройте ссылку `source.url` и сверьте цифры и даты с первоисточником;
   - убедитесь, что шаги не звучат как совет «купить/продать» и не обещают доход (сборка такие фразы всё равно отклонит);
   - поправьте формулировки, если нужно; `"critical": true` ставьте только для действительно важных новостей (они выделяются бордовым).
3. Замените `"status": "draft"` на `"status": "published"` и заполните проверку:
   ```json
   "review": { "by": "Ваше имя", "at": "2026-09-21T12:00:00Z" }
   ```
4. **Commit changes**. Сайт обновится сам через 1–2 минуты. Если карточка не прошла проверку, во вкладке Actions задача покажет красный крестик и причину — прежняя версия сайта останется как была.

Лента показывает только новости за последние 24 часа, но карточка остаётся на сайте и попадает в архив.

## ИИ-разбор организаций (сервер)

На странице «Проверка организации» после данных реестра появляется блок «Разбор ИИ»: простым языком, что видно из данных
и что проверить дальше. Для этого нужен небольшой сервер `server/index.mjs` (зависимостей нет). Он держит у себя ключи
DaData и Gemini, чтобы их не было видно в браузере. В ИИ уходят только сведения об организации, без ФИО руководителя и адреса.
Ответ ИИ проверяется теми же правилами, что и новости, плюс запрет на вердикты вроде «надёжная компания».

Размещение на Timeweb Cloud (App Platform → Добавить → Backend, Node.js, репозиторий sut-site, ветка main):

- команда запуска: `npm run server`, сборка не нужна;
- переменные: `DADATA_TOKEN`, `GEMINI_API_KEY`, при желании `GEMINI_MODEL`, `ALLOWED_ORIGINS`
  (по умолчанию `https://fin-check.shop,https://www.fin-check.shop`), `AI_DAILY_LIMIT` (по умолчанию 300 разборов в сутки),
  `AI_PER_IP_HOUR` (по умолчанию 15 в час с одного адреса);
- домен, например `api.fin-check.shop` (A-запись на IP приложения).

Затем в приложении с сайтом добавьте переменную `ORG_API_URL` = адрес сервера (например `https://api.fin-check.shop`)
и пересоберите сайт. Пока `ORG_API_URL` не задан, страница работает по-старому, без ИИ.

Проверка сервера без интернета и ключей: `npm run test:server`.

## Запуск на своём компьютере (по желанию)

Нужен Node.js версии 20 или новее (<https://nodejs.org>).

```bash
npm run preview        # собрать сайт с демо-карточками и открыть на http://127.0.0.1:4173
npm run build          # собрать настоящий сайт в папку dist/
npm run fetch          # забрать новости из лент
npm run draft          # сделать черновики (нужна переменная ANTHROPIC_API_KEY)
npm run draft:mock     # то же без ИИ и без ключа — только проверить, что всё работает
npm run review         # список черновиков; npm run review -- <id> "Имя" — опубликовать проверенный
npm run check          # проверить все карточки и курсы
```

## Свой домен (по желанию)

1. Купите домен у любого регистратора; цены и правила смотрите у регистратора.
2. GitHub: **Settings → Pages → Custom domain** — введите домен и следуйте подсказкам GitHub про DNS-записи.
3. **Settings → Secrets and variables → Actions → Variables** — добавьте `SITE_URL` со значением `https://ваш-домен.ru`. Затем запустите **«Опубликовать сайт»** ещё раз.

## Добавить новые источники новостей

В `config/sources.json` для Минфина, ФНС и Росстата места уже подготовлены, но адреса лент **не проверены** —
найдите на сайте ведомства значок RSS, скопируйте адрес в `url` и поставьте `"enabled": true`.
Проверьте, что лента открывается в браузере и что условия сайта разрешают использовать её материалы. Сначала запустите `npm run fetch` и посмотрите, что пришло.

## Курсы и видео сторонних авторов

Материал попадает на сайт только если в `content/courses.json` заполнены все поля, **включая `consentDate` — дату согласия автора**
(храните переписку с автором, где он согласился). Пример записи:

```json
{
  "items": [
    {
      "id": "kurs-primer",
      "kind": "course",
      "title": "Название курса",
      "author": "Имя автора",
      "url": "https://example.com/kurs",
      "consentDate": "2026-09-01",
      "updatedAt": "2026-09-21",
      "topics": ["budget"],
      "affiliate": true
    }
  ]
}
```

`kind` — `course` или `video`. Список допустимых `topics` — в `content/topics.json` (поле `id`). Партнёрские ссылки на сайте помечаются, правила описаны на странице «Как мы работаем». Если запись заполнена не до конца, сайт её не покажет, а `npm run check` объяснит, чего не хватает.

## Перед показом людям

- `config/site.json`: заполните `contactEmail` и `editorialContact` (чтобы можно было сообщить об ошибке), `telegramUrl`, если есть канал.
- `subscribeFormAction`: адрес формы рассылки (например, от сервиса рассылок). Пока пусто — блок подписки не показывается.

## Чего пока нет

- Персональных рекомендаций организациям по данным о компании: нужен выбранный источник данных и юридическая проверка (данные ИП — персональные).
- Рассылки на почту и Telegram-дайджеста.
- Реальный вызов Claude API проверяется только после добавления ключа.
