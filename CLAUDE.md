# INNSIDER

- Название сайта — **INNSIDER** (латиницей, заглавными, как логотип). Прежние названия «Суть», «ИННфакт», «СверкаИНН», «ИННсайдер» больше не используем — ни в коде, ни в текстах, ни в ответах владельцу (история переименований — HANDOFF.md, разделы 11–12).
- Главный адрес — inn-sider.ru. innfact.ru, fin-check.shop, sverkainn.ru, inn-saider.ru — редиректы на него. API — api.fin-check.shop (старый адрес продолжает работать).
- Название задаётся в `config/site.json` (`name`). Подписка — «INNSIDER Ultima».
- «Инсайдер» — только образ: сайт работает с открытыми данными, никакой закрытой информации не обещаем (224-ФЗ, ст. 185.6 УК).
- Владелец общается по-русски — отвечать по-русски.
- Сервер и его обслуживание — навык `.claude/skills/innsider-server`.
