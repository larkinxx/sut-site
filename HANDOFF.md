# «Суть» (fin-check.shop) — передача проекта

Документ для нового помощника (ChatGPT или другого ИИ) и для разработчика. Состояние на 25 сентября 2026 г.
Код: https://github.com/larkinxx/sut-site (ветка `main`). Владелец — Владимир (CEO), общается по-русски.

## 1. Что это за проект

**«Суть»** — сервис проверки компаний и ИП по ИНН с понятным разбором и советами бизнесу.
Основа — проверка организаций; вокруг — экономические новости с разбором «что это значит для вас»,
финансовые калькуляторы и раздел о законном снижении налогов. Слоган: **«Введите ИНН — узнайте суть»**.

Позиционирование: не «ещё один Rusprofile» (у него 38 источников — по полноте данных не конкурировать),
а сервис для **владельца малого бизнеса**: не пересказ реестра, а следующий шаг — риски, что проверить,
как законно платить меньше налогов, за чем следить. Подробное сравнение: `Claude outputs/sut-vs-konkurenty.pdf`.

## 2. Правила, которые нельзя нарушать

- **Язык и тон**: весь текст сайта по-русски, простым языком, без канцелярита.
- **Слово «ИИ» не выносить в заголовки и маркетинг** — владелец считает, что это удешевляет проект.
  Честные пометки оставлены: «подготовлено автоматически», раскрытие передачи данных в ИИ-сервис мелким шрифтом,
  объяснение на странице «Как мы работаем».
- **Без вердиктов** «надёжная / ненадёжная компания», без баллов; без обещаний дохода и «покупайте/продавайте»
  (проверки в `src/lib/schema.mjs` → `FORBIDDEN`, и в `validateAi` на сервере).
- **Налоги — только законные способы.** Схемы (дробление, «технические» фирмы, сотрудники как самозанятые и т. п.)
  описываются только как предупреждение. ИИ-ответы с советами схем отсекаются в `validateAi`.
- **152-ФЗ**: персональные данные пользователей (аккаунты) хранятся только на сервере в России (Timeweb).
  ФИО/ИНН руководителей и учредителей из «Прозрачного бизнеса» наружу не отдаём — только количества.
- **Капчи не обходить** (pb.nalog.ru) — при капче сервер делает паузу 2 часа.
- **Секреты** (ключи API, пароли) владелец вписывает сам на сервер; в чат и в репозиторий их не класть.

## 4. Структура репозитория

- `src/build.mjs` — сборка всех страниц (шаблон, новости, калькуляторы, раздел «Налоги», вход/кабинет, sitemap, RSS).
- `src/lib/` — `content.mjs` (загрузка контента), `schema.mjs` (проверка карточек новостей), `taxes.mjs` (тексты раздела «Налоги» и схем), `util.mjs`.
- `public/` — `app.js` (лента, калькуляторы, «Поделиться/Сохранить расчёт», виджет ставки ЦБ), `org.js` (проверка по ИНН, памятка, налоговые советы `taxIdeas`, блок ФНС), `account.js` (вход и кабинет), `style.css`, шрифты PT Serif, иконки, `og.png`.
- `server/index.mjs` — API: `/api/org`, `/api/org/ai`, `/api/org/fns`, `/api/org/suggest`, аккаунты.
- `server/accounts.mjs` — вход (Яндекс ID, Telegram, код на почту), кабинет, слежение за компаниями, SMTP-клиент.
- `server/fns.mjs` — данные ФНС: открытые данные (из `fns.db`), ГИР БО, «Прозрачный бизнес».
- `scripts/` — `fetch.mjs`, `draft.mjs` (новости), `rates.mjs` (ставка ЦБ), `telegram.mjs`, `fns-import.mjs` (импорт открытых данных ФНС, cron 26-го числа).
- `config/` — `site.json` (название, контакты, **operator** — пустой!), `finance.json` (все ставки и лимиты для калькуляторов и советов, сверены 25.09.2026), `sources.json`.
- `deploy/` — установка и обслуживание сервера.
- `Claude outputs/` (не в git) — логотипы, визитки (бумажная и металлические), PDF сравнения с конкурентами.

**Проверки перед пушем**: `npm run test:server` (39 тестов: сервер, аккаунты, ФНС), `npm run build`, `npm run check`.

## 5. Что уже работает на fin-check.shop

- Лента новостей за 24 ч с разбором по аудиториям, архив, карточки, RSS, виджет «ключевая ставка / инфляция / следующее решение ЦБ».
- Калькуляторы: кредит, досрочное погашение, вклад, налог на вклады, самозанятый или ИП; «Поделиться расчётом».
- **Проверка организации по ИНН** (через api.fin-check.shop): данные DaData, ссылки на реестры и ЦБ,
  экспресс-разбор (Алиса — Yandex AI Studio, модель aliceai-llm), памятка, налоговые советы владельцу,
  **блок «Финансы и налоги» по данным ФНС**: режим, численность, уплаченные налоги, налоговый долг с расшифровкой,
  отчётность за 5 лет с графиком, сигналы (убыток, падение выручки, отрицательный капитал, долг).
  Открытые данные ФНС в базе на сервере: 1,3 млн режимов, 2 млн — численность, 2,6 млн — налоги, 874 тыс. — долги.
- Раздел «Налоги»: законные способы по видам налогов, «Опасные налоговые схемы», «Блокировка счёта по 115-ФЗ»; «Не становитесь дропом».
- Логотип «С.» в кольце, favicon, иконки, превью для соцсетей.
